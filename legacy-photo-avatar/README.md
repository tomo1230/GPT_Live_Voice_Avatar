# NEON — Local Virtual Human

完全ローカルで動作する音声駆動バーチャルヒューマンです。
VBCABLEなどの仮想オーディオ入力をブラウザ内で解析し、入力音声から直接リップシンクと身体動作を生成します。
音声の録音、文字起こし、サーバー送信は行いません。

## 現在できること

- VBCABLE（`CABLE Output`）を含む音声入力デバイスの選択
- 入力音声の実波形によるリアルタイム・リップシンク
- 低域・中域・高域から口幅、眉、うなずき、頭の傾きを合成
- フォルマント帯域から「あ・い・う・え・お・閉口」を連続推定
- 目が先に対象へ動き、頭と肩が遅れて追従する視線モデル
- バネ物理による動きの行き過ぎ、減速、自然な静止
- 実写写真ベースの顔・髪・肩ポートレート
- 本人写真から作成した「あ・い・う・え・お」の母音口形と閉眼素材
- 上位2母音の重み付き合成による滑らかな口形遷移
- 顔ランドマーク三角形メッシュによる口周り・下顔面の連動変形
- 写真上へ重ねる瞬き、呼吸、微細な頭部モーション
- 瞬き、呼吸、視線、発話立ち上がりの状態アニメーション
- 右パネルの「あ・い・う・え・お・瞬き」ボタンによる素材プレビュー
- 口の感度と動作量をリアルタイム調整
- APIキー不要、`127.0.0.1`だけで待ち受け
- STT・LLM・TTS・GPUモデル不要

## 起動

Node.js 20以上だけでUIを起動できます。

起動:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-local-human.ps1
```

ブラウザで `http://127.0.0.1:4782` を開き、マイク権限を許可します。
「入力デバイス」から `CABLE Output (VB-Audio Virtual Cable)` を選択してください。

## 音声から生成する動作

処理は `public/app.js` 内のWeb Audio APIだけで完結します。

- RMS音量: 口の開きと閉じる速度
- F1/F2フォルマント帯域: 母音口形
- 高域成分: 口幅と眉の持ち上げ
- 低域成分: 頭部と肩の重い動き
- 発話立ち上がり: 軽いうなずき
- 発話中のリズム: 慣性付きの頭の傾きとうなずき
- 無音時: 非周期的な視線移動とマイクロモーション

GPUモデルをロードしないため、VRAM消費はブラウザ描画分だけです。
